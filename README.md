# Trip Analysis using Statistics, Probability & Linear Algebra

## 📌 Project Overview

This project performs a complete statistical and mathematical analysis on a ride-sharing dataset using **Python, NumPy, Pandas, Linear Algebra, Probability, and Statistical Testing** techniques.

The objective of this project is to analyze ride data and identify business insights related to:

- Fare pricing
- Trip distance
- Surge pricing
- Customer ratings
- Peak-hour revenue
- Ride demand patterns
- Statistical significance in operational decisions

| Fare_Amount | Total fare charged |

# 🔍 Key Findings

## 1. Trip Distance vs Fare Amount
- Very weak correlation observed.
- Trip distance does not significantly affect fare amount.

## 2. Premium vs Economy Pricing
- Premium rides are not statistically more expensive than Economy rides.

## 3. Surge Pricing vs Ratings
- Surge pricing has minimal impact on customer ratings.

## 4. Peak vs Non-Peak Revenue
- No significant revenue difference detected.

## 5. Outlier Detection
- Only one mild fare outlier found.

## 6. Ride Demand
- Economy rides have the highest demand probability.
